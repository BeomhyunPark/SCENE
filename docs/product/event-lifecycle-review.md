- 소스: [이슈 #8 사용자 답변](https://github.com/BeomhyunPark/SCENE/issues/8#issuecomment-5903987318)

## 행사 상태와 권한

| 상태 | 의미 |
| --- | --- |
| 준비 중 (기존 DRAFT 후보) | 활성화 전 준비 |
| ACTIVE | 실제 행사 운영 중 |
| ENDED | 현장 운영 종료. 정산·회고·후속 정리 가능 |
| ARCHIVED | 일상 작업 목록에서 분리한 과거 기록. 읽기 전용 |

활성화·종료·재개는 Event Owner가 실행한다. 일반 운영자에게 자동 허용하지 않는다. Organization Owner는 담당 Owner 부재·복구 등 조직 관리 상황에서 Override할 수 있다. 조직 전체 조회가 모든 행사의 일상 종료·재개 권한을 뜻하지 않는다.

보관은 ENDED 행사에 대해 Event Owner 또는 Organization Owner가 실행한다. 보관 해제 권한의 정확한 집합·Override 조건/사유/감사·Permission 이름과 부여 방식은 기술 계약에서 명시한다. 조직 Owner를 모든 행사의 상시 Owner로 자동 지정하지 않는 #4 기준을 유지한다.

## 종료 확인

미완료 업무·미정산·미배정·미전송 안내 등이 남아 있어도 종료할 수 있다. 종료 전 수와 영향, 종료 후 정산·회고·기록 정리를 계속할 수 있다는 안내를 보여주고 명시적 확인을 받는다. 운영상 미완료를 일반 종료 차단 조건으로 사용하지 않는다. 인증·권한·현재 행사 상태 검사는 유지한다.

업무를 사용하지 않은 행사에 참가자·회고·배정을 새로 만들도록 강제하지 않는다.

## 종료 후 허용 행동

| 행동 | ENDED | ARCHIVED |
| --- | --- | --- |
| 데이터·과거 기록 조회 | 기존 권한으로 가능 | 기존 권한으로 읽기 전용 조회 |
| 정산·회고·후속 업무 | 업무 권한에 따라 가능 | 보관 해제 후 처리 |
| 후속 공지 | 가능 | 읽기 전용. 먼저 보관 해제 |
| 참가 신청 | 종료 즉시 차단 | 차단 |
| 새 체크인·체크인 취소 등 현장 작업 | 차단. 과거 기록 조회 가능 | 차단 |
| 새 조 편성·참가자 대상 재공개 | 차단. 마지막 공개본은 기록으로 유지 | 차단 |
| 현장 일정 운영 | 차단 | 차단 |
| 기록 오류 정정 | 일반 운영 변경과 구분해 제한적으로 허용. 사유·이력 기록 | 먼저 보관 해제 |

종료는 참가 신청을 닫는다. 신청 접수 상태가 별도 개념이어도 종료된 행사에서 신청을 계속 받지 않는다. 재개 시 기능 사용 가능성을 설명하되 과거 신청 설정·마감 시각·업무 권한을 무조건 변경하거나 모든 신청을 자동으로 여는 결정은 아니다.

마지막 공개 편성 보존은 기록 유지다. 취소자·현재 권한 회수자를 다시 조회할 수 있게 하는 근거가 아니며 #3·#7의 접근 검사를 유지한다. ENDED에서 일반 편성 Undo·저장·재공개로 현장 운영을 우회하지 않는다. 정정이 필요하면 별도 정정 경계를 사용한다.

정정 가능한 필드·담당자·체크인/편성 이력의 정정 방식, 참가 취소·복귀 요청과 지연 알림 재전송의 종료 후 처리 범위는 후속 세부 계약에서 정한다. 후속 공지 허용이 과거 편성 알림을 언제든 재전송해도 된다는 결정은 아니다.

## 재개

ENDED → ACTIVE 재개를 허용한다. 영향 안내와 사유 확인을 제공하고 실행자·시간·사유를 History에 기록한다. 재개는 현재 행사에 새 전이를 적용하며 종료 이전 데이터 전체를 되돌리지 않는다. 종료 후 정산·후속 공지·정정도 유지한다.

참가 신청·체크인 등 운영 기능이 다시 사용 가능해질 수 있음을 설명한다. 세부 활성화 조건·신청 설정·동시 요청·중복 실행·실패 복구는 기술 설계에서 정한다.

## 보관·해제·재진입

ACTIVE → ARCHIVED 직접 전이는 차단한다. ACTIVE → ENDED → ARCHIVED 순서를 따른다. 미완료 후속 업무가 남아 있으면 강하게 경고하되 명시적 확인 후 보관할 수 있다. 이후 수정하려면 먼저 보관을 해제한다.

보관은 삭제가 아니다. 기본 작업 목록에서 숨기고 별도 보관 목록·검색으로 찾아 읽기 전용으로 진입한다. ENDED 진입 시 현장 운영 종료·후속 정리 가능 안내, ARCHIVED 진입 시 보관·읽기 전용 안내를 제공한다. 보관 해제 행동은 실행 권한이 있는 사용자에게 제공한다.

ARCHIVED → 보관 해제 → ENDED → 재개 → ACTIVE의 두 행동을 분리한다. 보관 해제만으로 신청·체크인·편성 운영을 다시 열지 않는다.
