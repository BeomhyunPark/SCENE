## 전 → 후

| 화면 | 전 | 후 |
|---|---|---|
| 목록 | 목록 위에 늘 펼쳐진 폼(업무 제목·시작일 (선택)·마감일 (선택)·업무 추가) | 보기 전환 줄 오른쪽 "+ 업무 추가" → 서랍 "새 업무 만들기"(업무명·담당자·시작일·마감일, 취소·업무 만들기) |
| 월 달력 | 날짜를 누르거나 끌면 위 폼의 기간이 채워지고 제목 칸으로 이동 | 같은 동작으로 기간이 채워진 서랍이 열림(휴대폰 날짜별 목록의 "+ 업무"도 같음) |
| 목록 행 | 카드마다 제목·상태·담당·기간·체크 수 | 그대로 카드 하나씩(scene-press--card·꺾쇠 #491). 휴대폰에선 제목 줄 + 담당·기간 줄로 접힘 |
| 상세 머리 | 업무 제목(h1) + 본문에 같은 제목 입력 칸 | 머리는 "준비 업무"(목록과 같음), 본문 맨 위 제목이 곧 고치는 칸(테두리 없이 제목 글씨, 가리키면 테두리) |
| 상세 저장 | "제목 저장"·"기간 저장" 버튼 | 버튼 없음. 제목은 칸을 떠나거나 Enter, 기간은 두 날짜 칸을 모두 떠날 때 저장. Esc는 제목을 되돌림 |
| 상세 배치 | 한 줄씩 쌓인 입력·버튼 | 왼쪽 제목·체크리스트("체크리스트" n/m 완료), 오른쪽 속성 패널(현재 상태 칩·담당자·시작일·마감일 → 구분선 → 업무 완료 / 업무 취소·업무 삭제). 휴대폰에선 위아래 |
| 상세 버튼 | 완료(Primary)·업무 취소(Secondary)·삭제(Danger 채움) | 업무 완료(Primary, 패널 폭)·다시 진행(끝난 업무만, #490 규칙 그대로) / 업무 취소·업무 삭제(Tertiary). 확인 다이얼로그는 그대로 |

박스: 상세 안에 박스는 입력 칸뿐이고, 패널은 세로선 하나, 체크리스트·버튼 묶음은 가로 구분선으로 나눴다. 읽기 전용(권한 없음·보관)일 때 담당자·기간은 라벨-값 글자로 보인다.

## 그대로 둔 동작

- 권한 없음(TASK_WRITE 없음): "+ 업무 추가"가 없고, 상세는 제목이 글자, 담당자·기간이 라벨-값.
- 버전 충돌·완료 불가 사유·취소된 업무·보관된 행사·찾을 수 없음·멤버 아님·네트워크 실패 안내: 문구와 처리 그대로. 실패하면 친 제목은 칸에 남는다.
- 시작일만 있고 마감일이 없거나 순서가 거꾸로면 서버로 보내지 않고 기존 문구 "마감일을 확인해 주세요. …"를 보인다(이전엔 서버가 같은 문구를 돌려줬다).
- 추천 업무 보기(DEC-066), 목록/월 전환, 월 격자, 날짜 없는 업무.

## 테스트 변경(같은 뜻으로)

- 목록: "업무 제목" 칸·"업무 추가" 제출 → "업무 추가"로 서랍을 열고 "업무명"·"업무 만들기". 읽기 전용은 "업무 추가" 버튼이 없음으로 확인. 월 선택은 서랍에 기간이 채워지고 만들면 그 기간으로 보내는 것까지 확인.
- 추천 실패 때 직접 추가: 입력 칸이 늘 있던 것 → "업무 추가"를 누르면 업무명 칸이 나옴.
- 상세: "제목 저장" 클릭 → 제목 칸을 고치고 떠남. "완료"·"삭제" → "업무 완료"·"업무 삭제".
- 추가: 서랍에서 담당자를 골라 만들면 assigneeUserId를 보냄, 서랍의 빈 제목 안내·Esc·취소, 바뀌지 않은 제목은 보내지 않음, 기간은 두 칸을 다 떠난 뒤 저장하고 시작일만 있으면 보내지 않음.
