# #469 데스크톱 운영자 화면 본문이 헤더 제목과 같은 열에서 시작한다

2026-11-25, 목업 서버(`VITE_API_MOCK=1 pnpm dev`) + 미리 설치된 Playwright. 실제 서버·실기기 클릭은 하지 않았다.

## 확인 방법
`audit.mjs`가 `OperatorShell`을 쓰는 24개 경로를 1440·2000px(사이드바 펼침 / 접힘 `c`)과 390px에서 열고,
헤더 제목(`.operator-shell__heading`)의 왼쪽 끝과 본문 첫 내용의 왼쪽 끝(px)을 잰다. 결과는 `before/audit.txt`, `after/audit.txt`,
스크린샷은 `before/before-<화면>-<폭>.png`, `after/after-<화면>-<폭>.png`. `compare-*-2000.png`는 위가 전, 아래가 후.

- 390px: 전후 측정값이 완전히 같다(데스크톱 규칙만 바뀜).
- `events/new`(행사 만들기)는 framed가 아니라 가운데 정렬 폼이다. 쏠림 문제와 반대 모양이고 이 이슈 범위 밖이라 그대로 두었다.

## 남은 점
- 조 편성 보드는 2000px에서 전에는 화면 끝까지 넓게 깔렸는데 이제 1128px 열 안에 들어간다(한 줄 카드 수가 줄어듦).
- 현장 운영 하단 "새로 고침" 바와 일정 하단 저장 바는 휴대폰 여백(16px)에 맞춘 음수 margin이라 데스크톱에서 본문보다 양쪽 16px 넓다. 두 화면 재설계(#468, #466)에서 정리한다.
