## 무엇을 했나

- `capture.mjs`: 운영자 32개·참가자 7개·공개 4개 경로를 1440(사이드바 펼침)·390(휴대폰)으로 찍고(deviceScaleFactor 2, 전체 페이지), 본문(`.operator-shell__main`, 없으면 `main`) 안에서 보이는 버튼·링크·입력 칸·제목·문구를 뽑았다. 결과: `before/before-<화면>-<폭>.png`, `before/before-inventory.json`, 실행 출력 `capture-before.log`.
  - 시드: 진행 중 행사, 일정 7개(공개됨), 신청 40명, 조 15개·조 편성 대상 150명(`?mockGroups=150&mockGroupCount=15`), 업무 4개, 공지 1개. 회고는 같은 행사를 종료 상태로 바꿔 찍었다. 참가자 화면은 신청자 "김가람"으로 들어갔다.
  - 버튼 수에는 표의 행 버튼(조 편성 카드, 체크인 버튼 등)이 함께 들어간다. 아래 표는 행 반복을 하나로 묶어 적었다.
- Figma: 제품 UI 파일 `RreFdEVMiwgHrV7teaCEOm`의 live 페이지 262:7 프레임 목록을 읽고(`get_metadata`), 판단에 쓴 프레임은 스크린샷으로 대조했다: P02-01 행사 목록(264:25382), ARCHIVE v2.0 행사 목록(46:18265), P03-01 참가 현황(265:10253), P07-01 준비 업무(264:26192), P07-D01 업무 상세(264:26306).
- 코드: 눌러도 아무 일이 없는 버튼(onClick·href 없음)과 같은 곳으로 가는 링크를 소스에서 직접 확인했다.
