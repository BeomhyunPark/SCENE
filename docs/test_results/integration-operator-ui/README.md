## 남은 문제 (각 브랜치 안의 판단이라 고치지 않음)

1. **시간표 15분 블록(#466)**: `16:00–16:15 운영진 점검`은 데스크톱 34px·휴대폰 40px 높이라 제목 줄 아래가 잘리고(V), 현재 시각 선(16:20)이 블록 글자 위를 지난다(NOW). 모든 폭에서 같다. 개별 브랜치 스크린샷과 같은 증상이며 통합으로 달라지지 않았다. 짧은 블록을 한 줄(시각 · 제목)로 줄이거나, 현재 시각 선을 블록 아래로 보내는 등 #466의 디자인 판단이 필요하다.
2. **시간표 1시간 블록 태그(#466)**: 데스크톱에서 `13:00–14:00 도착·등록`, `18:00–19:00 저녁` 등 1시간 블록의 장소·분류 태그 줄이 블록 아래 테두리에 붙어 아래쪽이 조금 잘린다. 휴대폰(390)은 블록이 더 높아 잘리지 않는다. 끝 시각 없는 `21:40 간식` 블록은 태그 줄이 거의 가려진다(V).
3. `17:30–17:50 단체 사진`은 한 줄 표시로 바뀌어 잘림은 없지만, 측정상 태그 상자 오른쪽이 블록 경계에 닿는 경우가 있다(H, 눈으로는 문제 없음).
