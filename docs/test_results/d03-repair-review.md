# D03 저장 완료 편성 보드 재진입

상태: Review. [이슈 #15](https://github.com/BeomhyunPark/SCENE/issues/15), 상위 감사 #10.

## 수정

참가 현황의 조 편성 메뉴와 첫 편성 저장 후 행사 홈의 조 편성 메뉴·카드가 1조 상세 모달에 잘못 연결되어 있었다. 배정 1명·미배정 103명 상태의 저장 완료 보드를 만들고 세 진입점을 해당 보드로 연결했다.

기존 보드의 컴포넌트·스타일·폰트를 재사용했다. 새 보드에서 저장 전 안내, 취소·저장 조작, 다른 상태의 샘플 조 및 맞지 않는 시간대 요약을 제거했다. 김민수는 1조에 남고 미배정 수는 103명을 유지한다. 상세 버튼은 별도의 1조 상세 모달을 연다.

[Figma 보드](https://www.figma.com/design/RreFdEVMiwgHrV7teaCEOm/?node-id=809-44362)

## 검증

후속 사용자 재검토에서 화면 밖의 복귀·예외 경로를 추가 수정했다. 최신 결과는 [경로 재수정 검토](cross-route-repair-review.md)를 따른다. 아래 검증은 최초 수정 당시의 범위다.

저장된 내비게이션 및 구조 검사 15/15 통과. `d03-reaction-check.json`에 결과, `d03-reaction-check.figma.js`에 Figma use_figma용 읽기 전용 재현 코드가 있다. `d03-repair-board.png`는 캔버스 캡처다.

실제 Present 클릭과 서버 저장 검증은 수행하지 않았다. 원본 감사 파일은 수정 전 증거로 유지한다. 미배정 이름의 배정 조작은 이후 [D04 수정 검토](d04-repair-review.md)에 기록했다.

## 종료 전 검토

- [ ] 첫 편성 저장 → 1조 상세 → 참가 현황 → 조 편성을 Present에서 재현한다.
- [ ] 보드의 배정 1·미배정 103 및 김민수 1조 상태를 확인한다.
- [ ] 상세 모달 닫기와 참가 현황·행사 홈 복귀 후 보드 재진입을 확인한다.
