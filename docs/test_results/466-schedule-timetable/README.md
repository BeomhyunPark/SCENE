## 후속: 블록 글자 잘림과 현재 시각 선 (2026-11-25)

통합 확인(`integration/operator-ui-figma`)에서 찾은 세 가지를 고쳤다. 같은 데이터·시각으로 390·1440·2000px 전(`10-fix-before-*`)/후(`11-fix-after-*`)를 찍었다(이 브랜치에는 통합 브랜치의 본문 최대 폭 1128px가 없어 데스크톱 칸이 더 넓다).

| 문제 | 고친 방법 |
|---|---|
| 15분 블록(16:00–16:15 운영진 점검)의 제목이 둘째 줄로 넘어가 잘리고, 현재 시각 선이 글자 위를 지남 | 짧은 블록은 한 줄(시각 + 지금·다음 + 제목, 넘치면 말줄임). 블록은 최소 30분 높이. **현재 시각 선은 블록 아래 층**에 두고 왼쪽 시각 눈금 칸부터 그어, 블록이 칸을 다 채워도 선이 보이게 함 |
| 데스크톱 1시간 블록의 태그 줄이 테두리에 걸려 잘림 | 블록 길이로 보여 줄 양을 정함(`blockDensity`): 45분 미만 한 줄, 70분 미만 시각·제목 두 줄, 70분 이상 장소·태그 줄까지. 172:3 프레임도 1시간 블록은 시각·제목만, 1시간 반부터 장소를 보인다. 태그 줄은 한 줄 높이로 막아 넘치는 태그는 통째로 빠짐 |

숨긴 장소·태그는 화면 낭독기용으로 DOM에 남는다. 참가자 블록은 눌러 펼치면 장소·바뀐 내용·설명이 모두 보인다. 공개 대기는 주황 점선 테두리, 지금은 강조 배경으로 짧은 블록에서도 보인다.

## 후속 2: 실제 그려진 크기로 판단 (2026-11-25)

재통합 확인(`integration/operator-ui-figma` f701749)에서 남은 세 가지. 분 단위 고정 기준(`blockDensity`)을 없애고 **블록마다 CSS 컨테이너 쿼리**로 실제 높이·폭에 들어가는지 본다. 통합 본문 폭은 스크립트의 `MAX_BOARD=1128`로 흉내 냈다(3일 보기 하루 칸 약 345px, 겹치면 약 171px). 전 `12-fix2-before-*`, 후 `13-fix2-after-*`(390·1440·2000).

| 문제 | 고친 방법 |
|---|---|
| 겹쳐서 좁은 15분 블록의 제목이 말줄임으로 사라짐 ("16:00–16:15 운영진 …") | 한 줄 블록은 제목 우선: 폭 200px 미만이면 끝 시각과 지금·다음 표시를 빼고("16:00 운영진 점검"), 120px 미만이면 제목만. 전체 시각·제목·장소는 `title`(툴팁)에, 링크 이름은 그대로 |
| 휴대폰 겹침 블록의 "조 모임" 태그가 오른쪽 테두리에 잘림 | 태그를 자기 줄(블록 폭 전체)에 두고, 한 줄에 안 들어가는 태그는 숨은 둘째 줄로 통째로 넘어감 |
| 1시간 블록이 자리가 남아도 장소를 숨김 | 높이로 판단: 47px 미만 한 줄, 66px 이상 장소, 87px 이상 태그. 휴대폰 1시간(80px)·데스크톱 1시간(68px) 모두 장소가 보임 |

참가자 블록은 눌러 펼치면 크기 제한이 풀려 모두 보인다. 컨테이너 쿼리는 jsdom이 계산하지 않아 자동 테스트로는 확인하지 못했고, 스크린샷으로 확인했다.
