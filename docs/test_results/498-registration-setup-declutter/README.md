## 실제 클릭 (`click-check.mjs` → `click-check.log`)

1440·390 모두: 질문 만들기·설정 저장(셀 질문 생김), "설명" 펼침(aria-expanded=true, 390에서 높이 40px), 직접 질문 추가, 순서 바꾸기(첫 칸 위로·끝 칸 아래로 버튼 0개), 신청 열기(제목 "신청 받는 중", 설정 중 배지 0개), 미리보기에서 부분 참석을 누르면 도착 질문이 나타남, 신청이 들어온 뒤 신청 닫기(제목 "신청 닫힘", 수정 줄 "신청은 닫혔지만…").

## 새로 넣은 문구

- **"신청 닫힘"**(신청이 들어온 뒤 닫혔을 때의 제목): 화면에 닫힌 상태를 부르는 말이 없었다. 같은 자리의 "신청 받는 중"과 버튼 "신청 닫기"에서 만들었다. 사용자 확인 필요.
- **"설명"**(묶음 설명을 펼치는 글자 버튼, 화면 읽기 이름 "○○ 설명"): Figma에 프레임이 없는 설정 카드의 접힘 단추라 기존 낱말을 썼다.

## 판단이 필요한 것

- 신청 기간: Figma A03-1에는 "9월 1일–10월 18일" 같은 기간 카드가 있지만 제품에는 신청 기간 기능이 없어 화면에는 "준비 중"만 있었다. 받는 중에도 "준비 중"이라 상태와 어긋나서 뺐다. 기간 기능을 만들 때 신청 상태 블록에 라벨-값 한 줄로 넣는 것을 제안한다.
- 닫힘 판단: 서버가 "열린 적 있음"을 따로 주지 않아, 신청이 하나라도 들어온 뒤(`locked`) 닫힌 것만 "신청 닫힘"으로 본다. 신청 없이 열었다 닫으면 받기 전과 같은 화면이다.
- "부분 참석을 받는 방식"에서 도착~출발을 고르면 설명 2줄("언제 도착하고…", "중간에 나갔다가…")이 함께 보인다. 둘 다 고른 방식의 결과라 남겼다.
