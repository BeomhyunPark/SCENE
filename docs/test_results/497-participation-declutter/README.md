## Figma와 다르게 둔 것

- **신청 설정으로 가는 길**: P03-01 도구 줄에는 정렬·필터·참가자 추가만 있고 신청 설정 버튼이 없다. 처음엔 "주소·QR" 다이얼로그 안에 두었으나, 사이드바에도 신청 설정이 없어 찾기 어렵다는 상위 세션 검토로 도구 줄에 "신청서 설정"을 두었다.
- **주소·QR 다이얼로그**: P03-01에는 없고 P12 O03은 별도 화면이다. 공용 `ConfirmDialog`(포커스 이동·가두기·Esc·포커스 복귀)를 썼다.
- **빈 상태**: O03의 "신청 받기" 카드 구성은 #483에서 남긴 카드 1장 그대로다.
