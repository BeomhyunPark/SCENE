# D05·D06·D12 실제 Present 검증

> 이 기록은 O01 확정 전의 역사적 검사다. 이후 [DEC-028 정책 반영·검증](2026-09-30-o01-policy.md)으로 신규 신청 마감과 수정 마감이 분리됐다. 특히 마감 안내 진입만으로 수정 금지를 판정하던 이전 기대값을 현재 정책으로 재사용하지 않는다.

검증일: 2026-09-30 (Asia/Seoul)

## 결론과 검증 범위

아래 9개 시나리오는 Chrome에서 Figma Present의 버튼을 실제로 클릭하고, 도착 URL의 node-id와 화면 문구를 확인했다. 확인한 범위에서 실패는 발견하지 않았다. 저장된 연결 구조를 읽은 검사와 구분되는 수동 실행 결과다.

Figma 프로토타입의 미리 채워진 신청·인증·회고 데이터를 사용했다. 실제 SMS 발송, 서버 저장, 접근 권한 검증이나 구현 코드 테스트를 수행한 것은 아니다. 이번 작업은 검증 기록을 추가하며 Figma 디자인 자체를 수정하지 않는다.

## 최초 실행에서 남아 있던 확인

- D05: 전화번호 변경·재인증 뒤 제한 유지, 편집 화면 직접 진입 후 저장 차단은 이번 실제 클릭 범위에 포함하지 않았다. 수정 가능 필드·시간 정책 O01은 별도 결정이 필요하다.
- D12: 비 Owner의 종료 차단, 경고/최종 확인의 취소·뒤로 가기, 회고 화면의 행사 목록 버튼은 이번 실제 클릭 범위에 포함하지 않았다. 준비 기록 체크박스를 클릭해 읽기 전용 동작을 확인하지도 않았다.
- 기존 보고서의 80/80·201/201 및 다른 누적 수치는 이번에 독립적으로 재실행하지 않았다. 이 보고서의 9개 수동 시나리오와 합산하지 않는다.
- 화면 캡처는 실행 중 도구 출력으로 확인했으며, 저장소에 PNG나 녹화 파일을 첨부하지 않았다. 이 기록은 수동 관찰 로그이며 자동 재현 테스트나 영상 증거가 아니다.
- #17·#18·#24는 이번 통과 범위와 미검증 항목을 함께 검토한 뒤 완료를 판단한다. 이 기록만으로 이슈를 자동 종료하거나 전체 QA 완료를 선언하지 않는다.

이하 보완 실행에서 위 항목 일부를 검증했다. 최초 9개 실행과 구분해 기록한다.

### QA 조건 주입 및 원복

기존 프로토타입에는 비 Owner로 전환하는 버튼이 없었다. P11·P12는 조건 분기 테스트를 위해 아래 두 BOOLEAN 기본값을 잠시 변경한 뒤 각각 새 Present 세션을 열었다. 실제 계정 권한을 변경한 것이 아니다.

| 변수 | mode | 원래 값 | QA 값 | 검증 후 값 |
| --- | --- | --- | --- | --- |
| `VariableID:826:44310` / `D05/directEditAllowed` | `646:1` | true | false | true |
| `VariableID:840:44405` / `D12/eventOwner` | `646:1` | true | false | true |

`figma-use`로 조건과 분기를 확인하고 값을 주입했다. 테스트 뒤 같은 API의 반환 값으로 두 변수의 true 원복을 확인했으며, 그 후 새 Owner 세션에서 P13·P14를 실행했다. D05 표시용 문자열 변수는 주입하지 않았으므로 P11은 저장 차단과 원본 참석 값 유지만 판정했고, 그 세션의 표시 문구 일관성은 판정하지 않았다.
