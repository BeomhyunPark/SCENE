## 화면별 변경

- **행사 홈**: 요약 카드 4개와 바로가기 카드 4개를 테두리 하나의 요약 줄로 합쳤다. 칸마다 링크이고, 칸 사이는 1px 구분선이다. 칸은 참가자(→참가 현황, 오른쪽 위 '신청 집계' 링크), 진행 중일 때 현장 운영(도착/전체, 미도착), 준비 업무, 일정, 변경 요청이다. 도착 수는 현장 운영 칸에만 둬서 참가자 칸과 겹치지 않는다. 지금 할 일·다가오는 일정·운영진 공지는 테두리 없는 세 섹션(휴대폰에서는 위아래)으로 두고, 행 사이를 구분선으로 나눴다. 빈 상태는 한 줄이다. 아이콘 타일과 '운영에 영향을 주는 항목부터 확인해요.'는 뺐다. 종료·보관 안내는 테두리 없는 연한 면이다.
- **현장 운영**: 참가자마다 있던 카드를 한 면 안의 목록 행으로 바꿨다. 조별 명단도 한 면에 담고, 조 사이와 조원 행 사이를 구분선으로 나눴다(박스 안 박스 없음). 선택한 행은 연한 배경과 왼쪽 막대로 표시한다. 넓은 화면에서는 행의 체크인이 글자 버튼(Tertiary 32)이고 패널의 버튼만 주된 버튼이다. 행에서 바로 체크인하는 흐름은 그대로다. 체크인 취소는 어디서나 글자 버튼이다. 패널의 읽기 전용 값은 라벨-값 행(조, 기록)으로 바꿨고, 이름 옆 상태 칩과 겹치던 '체크인: 미완료' 값은 뺐다. '왔어야 함 N명'은 채운 칩에서 경고색 글자 버튼으로, 수 칩 '8명'은 글자로 바꿨다. '식수 현황 보기'는 현황 줄 끝에 있다.
- **식수 현황**: 본문의 '식수 현황' 제목을 뺐다(헤더에 있음). 끼니별 박스와 같은 숫자를 다시 풀어 쓴 줄 대신, 날짜마다 표 하나(끼니·시각 | 예정 | 도착 반영 | 올 예정 | 아직 안 옴)를 둔다. 다음 끼니 행은 연한 배경과 '다음' 표시, 지난 끼니는 흐린 글자, 아직 안 옴이 있으면 경고색이다. 다음 끼니 블록에는 도착 반영과 복사 버튼만 남겼다.
