## Figma와 다르게 둔 것

- **"행사 홈" 버튼**: P16-26에는 있으나 사용자 결정(중복 제거)으로 뺐다. D04 v2 보드 머리에도 없다.

## 구현 메모

- 손잡이(button)는 DOM에서 체크박스 뒤에 두고 CSS `order: -1`로 맨 앞에 보인다. 손잡이를 DOM 앞에 두면 이름(label)을 누를 때 label의 첫 입력인 손잡이 버튼이 눌려 "이름을 눌러 고르기"가 깨진다(테스트 `moves several people at once from the bar…`가 잡았다).
- 고를 수 있는 행은 #491의 공용 눌림 규칙 `scene-press scene-press--row`(hover `bg/hover-row`, 눌림 `bg/subtle`)를 쓴다. 고른 행의 `bg/selected`가 hover보다 이기도록 선택자를 한 단계 더 구체적으로 썼다.
- 숙소의 숙박 안 하는 사람 행은 그대로 고르기·손잡이 없이 흐리게, "방에 넣을 수 없어요"를 같은 줄 끝에 보인다(DEC-085 동작 유지).
