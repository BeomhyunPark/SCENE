# 일정표 화면 (C4 #446, C5 #447) 확인 기록

2026-11-20. 로컬 서버(백엔드 `local` 프로파일, PostgreSQL 17 Docker) + 프런트 `VITE_API_MOCK=0 pnpm dev`, Playwright Chromium.
준비는 API로 했다: 새 행사(2027-01-22–24, ACTIVE), MANAGER 추가, 신청서, 참가자 둘(김조장·이조원), 1조 공개(김조장 조장).
클릭은 MANAGER(Local manager)로 했다.

| 확인 | 결과 |
|---|---|
| 데스크톱에서 항목 추가 → "저장하고 바로 공개" | `추가하고 공개했어요. 추가 1 · 변경 0 · 삭제 0 · 알림 2명` (1, 2) |
| 저장만 한 항목 4건 → 일정표 공개 확인 창 → 공개 | `공개했어요. 추가 4 · 변경 0 · 삭제 0 · 알림 2명` (3, 4) |
| 조장 대상 항목 | 조장 김조장에게만 "조장 모임"이 보이고 이조원에게는 없다. 운영진 항목은 둘 다 보이지 않는다 (5) |
| 참가자 홈 지금·다음 카드 | 행사 전이라 "첫 일정"으로 1일차 첫 항목 (6) |
| **휴대폰(390px)에서 고쳐 공개** | 행사 홈 → "일정표" → "18:00 저녁" → "10분 미루기" 3번 → 장소 입력 → "저장하고 바로 공개": **누른 것 6번 + 입력 1번**. 자동 클릭이라 걸린 시간은 0.7초(사람 손 시간이 아니다) (7, 8) |
| 참가자 화면 반영 | 열려 있던 이조원의 일정 탭에 공개 **19.5초 뒤** "변경됨"과 "시간 18:00–19:00 → 18:30–19:30", "장소 식당 → 본관 식당" (9) |
| 다른 미공개 변경 확인 창 | 저장만 한 "오전 집회"가 있을 때 "다른 미공개 변경 1건도 함께 공개돼요" → 함께 공개 → `추가 1 · 변경 1` (10) |
| 지우고 바로 공개 | `삭제 1`, 참가자 2일차에 **22.9초 뒤** "산책 취소됨" 줄긋기 (11) |
| 데스크톱 | 조장 일정 탭(12), 운영자 일정표 "모두 공개됐어요"(13) |

못 한 것: 운영 서버(scene.greengroove.app) 확인, 실제 휴대폰에서 사람 손으로 잰 시간, 웹 기본 시각 선택기의 한국어 표시(헤드리스 Chromium은 영어 "PM"으로 그린다), 신청서 칸 설정이 있는 행사에서의 칸 연결(이 행사는 설정이 없어 칸 목록이 없다. 칸은 mock 테스트로 확인), 알림함(B5 범위 밖).
