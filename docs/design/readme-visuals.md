# README 비주얼

README 배너는 [SCENE Product UI v3.0](https://www.figma.com/design/RreFdEVMiwgHrV7teaCEOm/?node-id=45-40)의 표지에서 로고, 색상과 기하학 그래픽을 가져왔다. 제품 소개에 맞춰 문구와 캔버스 높이를 조정했다.

| 로컬 파일 | Figma 소스 |
| --- | --- |
| `../assets/scene-symbol.svg` | Primary 로고의 symbol · `45:32` |
| `../assets/scene-wordmark.svg` | Primary 로고의 lockup text · `45:35` |
| `../assets/scene-geometric-field.svg` | 표지의 Geometric operation field · `45:42` |

SVG 에셋은 Figma에서 내려받은 원본을 유지한다. 로고 내부의 위치와 비율은 Primary 로고 `45:27`을 따른다. 표지의 배경 `#f8f9f7`, 패널 `#090b0b`, 본문 `#091213`, 보조 텍스트 `#4d5c5c`를 사용한다.

[배너 소스](readme-banner.html)는 원본 SVG를 참조하는 HTML/CSS다. 1600 × 800 캔버스를 브라우저로 렌더링해 `../assets/scene-banner.png`에 저장한다. PNG로 제공해 GitHub에서 로고와 한글이 동일하게 표시되도록 한다. Figma의 임시 다운로드 주소는 README에 사용하지 않는다.
